# Невъзможна София — етап A

Сцените използват предоставени снимки в координатите на основната фотография. Към този етап е налична само `planet.png`. Останалите шест бутона са видими, но изрично недостъпни, докато няма съответната снимка.

## Добавяне на снимка

Поставете оригиналния PNG в `public/scenes/ndk/special/` с името от регистъра в `src/special/registry.js`:

| Сцена | Очакван файл |
| --- | --- |
| Планета над София | `planet.png` — наличен |
| Полярно сияние | `aurora.png` |
| Ледникова София | `ice-age.png` |
| Пясъчна буря | `sandstorm.png` |
| София след 100 години без хора | `abandoned.png` |
| София 2150 — Cyberpunk | `cyberpunk.png` |
| Суперклетъчна буря | `supercell.png` |

Референтният размер е 1672 × 941 px. `npm run build` проверява размерите и генерира WebP, AVIF и `manifest.json`. PNG оригиналите остават непроменени. Не отбелязвайте сцена като готова без визуална проверка на действителната ѝ снимка и нужните за нея ефекти.

## Проверка на етап A

Пуснете `npm run build`, `npm run preview` на порт 8080 и `node tests/qa/impossible-sofia.mjs`. Тестът покрива десктоп, шест мобилни размера, панорамиране с емулиран допир, връщане към София, lite режим и fallback без WebGL. Снимките за преглед са в `docs/screenshots/impossible-sofia/`.

Емулацията в Chromium не замества проверка на физически Android телефон и Messenger. След предоставяне на останалите снимки са нужни отделни визуални проверки и реализиране на специфичните им атмосферни ефекти.
