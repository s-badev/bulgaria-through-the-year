# Напредък

Клон: `feat/living-photo-ndk`. Този файл стига, за да се продължи в нова сесия.

## Готово
- **M0** — git, клон, `.gitignore`, Vite скелет, одит на входа, доклад за подравняване (`docs/ALIGNMENT.md`), `ASSUMPTIONS.md`.
- **M1** — дълбочина (маршрут A), калибрирана геометрия, маски, обработка на вариантите, уеб активи, `scene.json`.
- **M2** — композитор: смесване на варианти в линейна светлина, пренасветляване, небе, правило за Витоша.
- **M3** — слънце (NOAA), час/DST, непрекъснати сезони, състояние, интерфейс, демо.
- **M4** — време: дъжд, сняг, мъгла, облаци, буря (безопасни проблясвания), вятър.
- **M5** — живот: трафик, лампи, фонтани, самолети, птици, насекоми, листа.
- **M6** — синтезиран звук със заглушаване и сила. Слято локално в `main`, проверено на http://localhost:8080.

## В ход
- **M7–M12** — „Сега“ с Open-Meteo (кодът е в `src/weather/now.js`), натрупване на сняг и мокро, достъпност, производителност, незадължителни варианти, пълен QA, документация.

## Следва
- QA решетка (4 сезона × 4 часа × 5 времена × 4 ширини), точност на слънцето спрямо Open-Meteo, README / ARCHITECTURE / QA, финално сливане.

## Отворени проблеми
- Комитите M3–M5 не се пускат поотделно (`main.js` е в комита M6); `main` се слива само на работещи точки.

## Как се пуска
```
npm install
npm run dev        # http://localhost:8080
npm run build && npm run preview   # продукционна версия на http://localhost:8080
npm run assets     # преработва активите от assets/source (само ако източниците са налични)
npm test           # слънце, DST, смесване на състояния
npm run qa         # решетка от екранни снимки (нужен е пуснат preview на 8080)
```
