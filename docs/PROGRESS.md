# Напредък

Клон: `feat/traffic-realism` (от `main@396ac00`), слива се локално в `main`. Този файл стига, за да се продължи в нова сесия.

## Готово
- **M0–M12** — живата снимка (виж историята в git и `docs/QA.md`).
- **Трафик** — фотографски коли по истинския асфалт; подробности, числа преди/след и решения в `docs/TRAFFIC.md`.
  - Геометрия на платната от снимката, изпечени коли, празни плочи, строга асфалтова маска, ленти с валидация (компилацията пада, ако лента напусне асфалта).
  - Библиотека от реални коли (матиране по разлика), едно инстансирано извикване, колите влизат в изображението преди пренасветляването.
  - Симулация: IDM, светофар, без застъпване, поява и изчезване само в декларираните краища, гъстота по час и време.
  - Clean-only зона (`left-out-slip`): само почистване, собствена геометрия; живата маска и лентите не се променят от нея.
  - Есенната, златната изгревна и зимната дневна снимка остават недокоснати там, където са прерисували пътя или колите им не се хващат; съответните платна се затварят, докато снимката се вижда (зимните нощи имат трафик).
  - Сенките на махнатите коли са махнати и от картата на изпечените сенки (иначе пренасветляването правеше бледи петна).
  - Светлините на колите следват околната светлина (малки точки при син час, ореол само в тъмното).
  - Буря: махнат светъл контур по билото под ниския облачен слой.
  - Dev слой (клавиш D): маска, ленти, скрити участъци, поява/изчезване, светофар.

## Следва (препоръчано)
1. `evening-golden.png`, `evening-bluehour.png`, `spring.png` в `assets/source/variants/` → `npm run build`. `evening-golden` е предварително недокосната и затворена; след преглед на плочата ѝ при 400% записът може да се махне от `UNTOUCHED` в `tools/roads-config.mjs`.
2. Дясното авеню: трасиране в сянката, ако се появи по-светъл вариант на тази част.
3. Звукът на колите (шум на гуми според гъстотата) и проверка на телефон.

## Отворени проблеми
- Виж „Останали проблеми“ в `docs/TRAFFIC.md` и „Какво не е проверено“ в `docs/QA.md`.

## Как се пуска
```
npm install
npm run dev                       # http://localhost:8080 (клавиш D: debug слой на трафика)
npm run build && npm run preview  # продукционна версия на http://localhost:8080
npm run assets                    # преработва активите от assets/source (само ако източниците са налични)
npm test                          # 25 теста: слънце, DST, смесване, Open-Meteo, ленти, дистанция, правила за поява, clean-only, изгрев
node tests/qa/traffic.mjs --port 8080        # 9 състояния: кадри при 4x + 5-минутен одит
node tests/qa/frametime.mjs main=PORT branch=PORT   # време за кадър без vsync
npm run qa                        # решетка + поведение + слънце (иска пуснат preview на 8080)
```
