# Напредък

Клон: `feat/living-photo-ndk`, слят локално в `main`. Този файл стига, за да се продължи в нова сесия.

## Готово
- **M0** — git, клон, Vite скелет, одит на входа, подравняване (`docs/ALIGNMENT.md`), допускания.
- **M1** — дълбочина (маршрут A), калибрирана геометрия, маски, обработка на вариантите, уеб активи, `scene.json`.
- **M2** — композитор: смесване в линейна светлина, пренасветляване, небе, правило за Витоша.
- **M3** — слънце (NOAA), час/DST, непрекъснати сезони, състояние, интерфейс, демо.
- **M4** — време: дъжд, сняг, мъгла по височина, фотографски облаци, буря, вятър.
- **M5** — живот: трафик, лампи, фонтани, самолети, птици, насекоми, листа.
- **M6** — синтезиран звук със заглушаване и сила.
- **M7** — „Сега“ с Open-Meteo и офлайн резервен вариант.
- **M8** — натрупване на сняг и мокро във времето, паралакс с предпочитане на далечното.
- **M9** — достъпност: намалено движение, „Без проблясвания“, клавиатура, мобилен лист.
- **M10** — адаптивно качество, поточно зареждане, маски на половин резолюция.
- **M11** — автоматично разпознаване на `evening-*` и `spring`, режим „само снимката“, запис на кадър.
- **M12** — документация, пълен QA (два паса), финално сливане.

## Следва (препоръчано)
1. Да се добавят `evening-golden.png`, `evening-bluehour.png` и `spring.png` в `assets/source/variants/` и да се пусне `npm run build`.
2. Да се чуе звукът от човек и да се настроят нивата в `src/audio/audio.js`.
3. Да се пробва на истински телефон (fps, жироскоп, долен лист) и в Safari/Firefox.

## Отворени проблеми
- Комитите M3–M5 не се пускат поотделно (`main.js` е в комита M6); `main` е слят само на работещи точки.
- Виж „Какво не е проверено“ в `docs/QA.md`.

## Как се пуска
```
npm install
npm run dev                       # http://localhost:8080
npm run build && npm run preview  # продукционна версия на http://localhost:8080
npm run assets                    # преработва активите от assets/source (само ако източниците са налични)
npm test
npm run qa                        # иска пуснат preview на 8080
```
