# България през годината · жива снимка на София

Истинска снимка на НДК и Витоша, която се променя непрекъснато според часа, сезона, времето и вятъра. Статичен сайт: без сървър, без платени услуги, без ключове.

## Пускане

```
npm install
npm run dev                       # разработка на http://localhost:8080
npm run build && npm run preview  # продукционна версия на http://localhost:8080
npm test                          # слънце, DST, смесване на състоянията, Open-Meteo
npm run qa                        # QA решетка + поведение + точност на слънцето (иска пуснат preview на 8080)
```

Изисква Node 20+ и браузър с WebGL 2. Обработените активи са в `public/scenes/ndk/` и са в git, така че чистият клон се компилира без входните снимки.

## Какво да пробваш първо

1. Плъзни **Час** от 19:00 към 22:00 през лятото: слънцето слиза вдясно, сенките се удължават наляво, лампите и прозорците светват на групи, трафикът пуска фарове.
2. **Есен → Мъгла** и плъзгача **Мъгла**: градът потъва, Витоша и върхът на кулата остават отгоре.
3. **Буря** (с „Без проблясвания“ и без него), после **Зима → Сняг**.
4. **Сега**: реалният час в София и времето от Open-Meteo.
5. **H**: само снимката. **Запази кадър**: PNG на текущия кадър.

## Нови снимки

Сложи файла в `assets/source/variants/` със същата композиция и размер (1672×941) и пусни `npm run dev` или `npm run build` — конвейерът забелязва промяната и преработва всичко.

| Файл | Какво замества |
|---|---|
| `evening-golden.png` | изчисления златен час вечер (светлина отдясно) |
| `evening-bluehour.png` | изчисления син час вечер |
| `spring.png` | изчислената пролет |

Правила за нови варианти: същата камера и кадър; без светлинни следи от коли, без падащ дъжд или сняг; за вечер светлината да идва отдясно.

## Преработка на активите от нулата

```
python -m venv .venv
.venv\Scripts\python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
.venv\Scripts\python -m pip install transformers pillow numpy
npm run assets
```

Стъпки: `extract-mock` → `depth.py` (Depth Anything V2 Small) → `align` → `build-masks` → `process-variants` → `build-scene`. Входът се чете от `assets/source/` (извън git): `ndk-photo.png`, `ndk-motion-mock.html`, `variants/*.png`.

## Нова сцена

Сцена = папка `public/scenes/<id>/` със `scene.json`, снимки, маски и геометрия. Двигателят не знае нищо за НДК: отваря се с `?scene=<id>`. Геометрията на НДК (платна, фонтани, коридори) е в `tools/scene-geometry.mjs`; за нова сцена се пише такъв файл и се пуска същият конвейер. Подробности: `docs/ARCHITECTURE.md`.
